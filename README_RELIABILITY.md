# Rewards 额度与异常积分修复（2026-10-23）

- 缺失、空数组或格式错误的手机搜索额度显示“未知”；接口明确返回的 0 额度保留为 0。未知额度不会被描述成任务已完成，也不会猜测账号应有额度。
- 积分只读接口在网络中断、响应不完整或服务暂时异常时最多尝试三次，每次间隔递增；401/403 等永久错误不重试。不会重新发送搜索、签到、领取积分等写入动作。
- 备用接口偏好按账号和设备分别保存，五分钟后重新检查主接口；备用接口失败后尝试恢复主接口。
- 账号中途失败时保留开始余额和最后确认余额，参与整轮积分合计；面板、历史明细和微信通知继续标记失败和最后确认值。
- 安装后读取 NAS 保存的会话，分别检查主接口及 Bing flyout 在手机、电脑会话下是否提供手机搜索字段。检查仅发送 GET，不运行搜索任务，不保存或输出 Cookie、Token、完整返回正文。

这是对锁定的 v4.3.2 镜像的可验证补丁。安装器在镜像内核对原始脚本哈希与补丁锚点；上游变化时停止构建。升级包不包含账号、会话、密码、Token 或运行数据库。

新部署构建时会应用补丁。已有部署升级前应手动暂停计划、确认空闲、备份并保留旧镜像；升级后检查服务健康、数据保留与界面显示，再决定恢复计划。历史 NAS 一次性安装器不随公开源码发布。

已有历史运行记录不会自动重算或覆盖；该修复应用于升级后的运行。
