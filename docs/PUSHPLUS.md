# PushPlus 微信推送

[返回首页](../README.md) · [文档目录](README.md)

配置入口：面板 → 配置 → PushPlus 微信推送。

1. 在 PushPlus 官网登录，关注其公众号并完成接收绑定和平台要求的实名认证。
2. 复制用户或消息 Token，在面板填写，按需勾选“启用微信推送”“全部成功时发送积分汇总”“失败、未完成或停止时提醒”，点击“保存通知设置”。
3. 点击“发送测试通知”，在手机微信确认收到。首次使用可先保持自动推送关闭，测试通过后再启用。

每轮任务真正退出后发送一条通知。全部成功时包含新增积分、总积分、耗时、各账号结果；任何账号失败、未完成、进程异常或主动停止时，按失败提醒开关发送异常/停止汇总，不再额外发送成功通知。PushPlus 配置独立于脚本原始 JSON，保存后立即生效，不需要打开脚本配置写入权限，也不会启用任务计划。通知需要面板服务保持运行，并能通过 HTTPS 访问 `www.pushplus.plus`。

Token 保存在持久化的 `data/dashboard/pushplus.json`（文件模式 600），同一文件记录最近提交结果和最近 100 次任务的去重标识。读取接口只返回是否已配置，不返回 Token；留空保存保留原值，填写新值替换，勾选清除时需同时关闭通知。Token 不写入浏览器存储、脚本配置或通知内容，账号邮箱脱敏，异常内容采用安全摘要。正常备份会包含该文件，因此备份也含敏感信息，应妥善保管。

测试通知使用已保存的配置，每 30 秒最多一次。平台响应 `code=200` 仅表示请求已受理，面板不会将其描述为手机已收到；最终收件请在微信或 PushPlus 消息记录中确认。网络超时不自动重发，以免重复；明确的临时 HTTP 拒绝最多重试一次。推送错误只记录通知结果，不影响积分任务。任务通知的去重记录会持久化，面板重连、重复状态和重启不会重新提交同一轮通知。

官方接口和限制：[消息接口](https://pushplus.plus/doc/guide/api.html)、[使用限制](https://pushplus.plus/doc/help/limit.html)。

## 积分明细与按账号分发

“运行记录 → 查看积分明细”展示该轮已保存的账号结果、新增积分、余额变化、耗时、已识别的积分来源及电脑/手机搜索汇总。明细保存在 Dashboard SQLite 的独立 `pushplus_account_details` 表中，不保存原始日志、密码、Cookie 或验证码；删除账号历史时同步清除此账号的明细。旧记录仅在仍有对应原始 RUN-START/账号事件时回填，日志已清理或缺失的字段显示未记录，不使用当前账号余额替代历史。

“配置 → PushPlus 微信推送”支持两种发送方式，升级默认保留原有汇总方式：

- 所有账号汇总到当前微信：原有行为，通知中附带可用的账号积分明细。
- 按账号分别发送：给每个微软邮箱绑定“当前微信”“指定 PushPlus 好友”或“不发送”。每个收件人只收到对应账号的结果、余额和已保存明细，不附其他账号和全体余额；本轮未参与的账号不会发通知。成功/失败开关按每个账号独立判断，某个接收人失败不会阻止其余接收人发送。

好友绑定步骤：在 PushPlus 的“我的好友”获取二维码，让另外两个微信分别扫码添加，再从好友列表复制各自的 32 位好友令牌。在面板对应微软邮箱下选择“指定 PushPlus 好友”并填写令牌，其他账号选择“当前微信”。保存后使用每个账号旁的“测试此接收人”。好友令牌直接填面板即可，不需要分享主 Token 给好友；服务器通过同一个已实名 Token 加 `to` 好友令牌发送。[官方好友说明](https://pushplus.plus/doc/function/friend.html)。

好友令牌不会回显，留空保留原值。绑定按邮箱保存，增删账号或列表顺序变化不会串绑。每位接收人测试独立限流；手动发送历史记录在按账号模式下也只向该轮有明细且已绑定的接收人分发。缺乏可分发明细时明确提示，保持原有汇总模式仍可发送整轮摘要。

新增账号绑定需要在面板保存后才启用。修改收件方式前确认绑定关系，并分别测试每个接收人。真实微信收件结果需要人工确认，私人部署报告不随源码发布。

## 手动发送历史运行记录

进入面板“运行记录”，在“运行历史”的“微信通知”列点击“发送本次汇总”；手机可左右滑动表格查看该列。发送内容为所选任务已保存的状态、开始/结束时间、已处理账号数、新增积分、积分总额和耗时，不会重跑任务。正在运行或缺少结束时间的记录不能发送。历史数据未保存的项目会写“未记录”，不会把当前账号积分作为过去的数据，也不会推送原始日志或未经筛选的异常文本。

手动发送使用配置页已保存的 Token，即使关闭自动推送也可手动发送。每 30 秒最多一次，发送冷却在面板重启后仍保留；自动通知的去重记录不受影响。PushPlus 返回“已受理”后，请在手机确认收到。最新一次手动发送结果也会显示在 PushPlus 配置区。

本仓库已包含手动发送功能；不会自行发送历史记录。已有部署升级前应关闭计划、确认空闲并备份账号、会话、通知配置和历史数据库。

历史一次性安装器及升级压缩包不随仓库发布。首次部署见 [部署指南](DEPLOYMENT.md)；源码归档生成见 [公开内容检查与打包](PUBLISHING.md)，不能将源码归档当作旧部署热更新包。
